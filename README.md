# Urban Flood Nowcasting System

A web app that shows flood risk on an interactive map and suggests safe routes that avoid flooded areas.

## Features
- Interactive flood risk map using Leaflet.js
- Safe route suggestion using Dijkstra's algorithm
- Flask backend serving the map and route data

## Tech Stack
- Python
- Flask
- Leaflet.js
- HTML, CSS, JavaScript

## How to Run
1. Clone the repo
2. Install dependencies: `pip install flask`
3. Run the app: `python app.py`
4. Open `http://127.0.0.1:5000` in your browser
